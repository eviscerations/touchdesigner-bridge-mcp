# Code of Conduct

## Our standards

This project is built to be useful to a wide range of people — developers, VJs, projection-mapping and
installation artists, media-server operators, technical directors, and anyone building real-time visuals in
TouchDesigner on Windows.

We expect contributors and community members to:

- Be respectful and constructive in issues and pull requests
- Focus feedback on the work, not the person
- Accept that different people have different use cases and hardware setups
- Help newcomers get set up — not everyone is a developer

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language
- Dismissing bug reports because they involve non-NVIDIA hardware or a non-commercial TouchDesigner license
- Spam or off-topic promotion

## Enforcement

Issues or pull requests that violate these standards will be closed. Repeat violations may result in being
blocked from the repository.

## Reporting

If you experience or witness unacceptable behavior, open a private vulnerability report or contact the
maintainer directly through GitHub.

---

This Code of Conduct is intentionally minimal. The goal is a functional, welcoming project — not bureaucracy.
